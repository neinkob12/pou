# PotPou Starter-Paket: Hier anfangen

Alles, was du brauchst, um PotPou mit Claude Code bis in den App Store zu bringen.

## Was drin ist

| Datei | Wofür | Für wen |
| --- | --- | --- |
| `CLAUDE.md` | Feste Regeln für Claude Code, wird automatisch gelesen | Claude Code |
| `TECH_STACK.md` | Technik, Ordnerstruktur, Setup-Befehle | Claude Code |
| `docs/KONZEPT.md` | Das komplette Spielkonzept mit Quellen | beide |
| `docs/SESSIONS.md` | 30 Sessions mit fertigen Prompts zum Kopieren | du |
| `docs/ASSETS.md` | Jede Grafik, jeder Sound, jede Größe, wo du es herbekommst | du |
| `docs/DESIGN_GUIDE.md` | Design-Entscheidungen Schritt für Schritt, Inspirationsquellen | du |
| `docs/STORE_LAUNCH.md` | Checkliste für Apple und Google, Review-Vorlagen | du |
| `docs/PROGRESS.md` | Fortschritt, wird von Claude Code gepflegt | beide |
| `src/game/config.ts` | Alle Balancing-Werte (fertig) | Claude Code |
| `src/game/timeEngine.ts` | Wachstum aus Zeitstempeln, inkl. Turbo (fertig, getestet) | Claude Code |
| `src/game/__tests__/` | 11 Tests, alle grün | Claude Code |

## Deine ersten 5 Schritte

1. **Heute:** `DESIGN_GUIDE.md` lesen und D1 bis D3 entscheiden (Name, Stil, Farben). Ca. 1 Stunde.
2. **Heute:** Apple- und Google-Entwicklerkonten beantragen (`STORE_LAUNCH.md`, oben). Das hat Wartezeiten.
3. **Diese Woche:** Moodboard bauen und die erste Budi-Probe zeichnen oder generieren (B4 + neutrales Gesicht).
4. **Dann:** Projektordner anlegen, dieses Paket hineinkopieren, Claude Code im Ordner starten.
5. **Session 1** aus `SESSIONS.md` kopieren und loslegen. Eine Session nach der anderen.

## Wie die Arbeit sich aufteilt

- **Claude Code** baut: Logik, Screens, Minigames, Käufe, Werbung, Build.
- **Du** lieferst: Entscheidungen, Grafiken, Sounds, Texte, Store-Konten, Tests auf dem Handy.
- Der größte Zeitfresser außerhalb des Codes sind die Grafiken. Fang damit früh an, parallel zu Block A.

## Grober Zeitplan

| Woche | Code (Claude Code) | Du parallel |
| --- | --- | --- |
| 1 | Sessions 1 bis 5 | Name, Stil, Moodboard, Konten beantragen |
| 2 | Sessions 6 bis 8, 10 | Budi-Set (B1 bis B12), Hauptraum (H1, U1, U2) |
| 3 | Sessions 9, 11 bis 13 | Minigame-Assets, Sounds sammeln |
| 4 | Sessions 14 bis 18 | Shop-Gegenstände, Sortenbilder |
| 5 | Sessions 19 bis 24 | Texte, Kosmetik, Datenschutz und Impressum |
| 6 | Sessions 25 bis 30 | Icon, Screenshots, Store-Einträge, Tester für Google |

Das ist ein ambitionierter Plan bei mehreren Sessions pro Woche. Rechne mit Puffer, vor allem bei Grafiken und Store-Review.
